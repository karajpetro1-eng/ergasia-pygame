# Παιχνίδι 2D σε Python & Pygame: Coin Collector

## Περιγραφή
Δισδιάστατο παιχνίδι δράσης αναπτυγμένο σε Python με χρήση της βιβλιοθήκης Pygame. Ο παίκτης καλείται να συλλέξει νομίσματα για να φτάσει τους 100 πόντους, αποφεύγοντας παράλληλα τον εχθρό που κινείται στον χώρο.

## Δομή Αρχείων
- `settings.py`: Περιέχει τις σταθερές, τα χρώματα και τις ρυθμίσεις ταχύτητας και οθόνης.
- `sprites.py`: Περιέχει τις κλάσεις `Player` (παίκτης), `Enemy` (εχθρός) και `Coin` (νόμισμα).
- `game.py`: Περιέχει τον κεντρικό βρόχο του παιχνιδιού (game loop), τον έλεγχο συγκρούσεων (collisions) και την απεικόνιση στην οθόνη.

## Οδηγίες Εκτέλεσης
1. Βεβαιωθείτε ότι έχετε εγκατεστημένη την Python 3.
2. Εγκαταστήστε τη βιβλιοθήκη Pygame με την εντολή:
   `pip install pygame`
3. Εκτελέστε το κύριο αρχείο του παιχνιδιού:
   `python game.py`

## Χειρισμός & Κανόνες
- **Κίνηση:** Χρησιμοποιήστε τα βελάκια (Πάνω, Κάτω, Αριστερά, Δεξιά) του πληκτρολογίου.
- **Νίκη:** Συγκεντρώστε 100 πόντους μαζεύοντας κίτρινα νομίσματα (+10 πόντοι το καθένα).
- **Ήττα:** Η επαφή με τον κόκκινο εχθρό μειώνει τη ζωή (Health). Αν η ζωή φτάσει στο 0%, το παιχνίδι τελειώνει.
